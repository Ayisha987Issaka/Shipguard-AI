# FoodNest Demo

FoodNest is a sample food-ordering API used to demonstrate ShipGuard AI.

## Requirements
- Node.js 20+
- npm

## Run
npm install
npm start

## API
GET /health

POST /api/payments

Example payment body:
{
  "amount": 100,
  "email": "customer@example.com"
}

## Deployment
Run the application with Node.js and configure the payment environment variables.
